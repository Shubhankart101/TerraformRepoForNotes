# Web application platform

## Use case

Provision a repeatable environment for a public web application with networking, an application runtime, secrets, monitoring, and separate dev/test/prod configuration.

## Terraform focus

- Resource groups and naming conventions
- App Service or container app hosting
- Key Vault integration
- Environment-specific variables
- Remote state and deployment approvals

## Advanced direction

Compose networking, identity, application hosting, and observability as versioned modules. Add private endpoints, managed identity, diagnostic settings, and policy checks before production use.
