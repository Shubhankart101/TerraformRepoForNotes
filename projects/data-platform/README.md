# Data platform

## Use case

Build a governed data platform for ingestion, transformation, storage, scheduling, lineage, and monitoring of business data.

## Terraform focus

- Data Factory or workflow orchestration
- Storage accounts and lifecycle policies
- SQL or managed database foundations
- Private networking and key management
- Diagnostic settings and data-platform tagging

## Advanced direction

Separate platform and workload state, use immutable storage policies, enforce private access, manage secrets with identity, and add policy checks for data residency and encryption.
