# AWS Terraform use cases

## Account and network foundations

- VPCs, subnets, route tables, security groups, IAM roles, tagging, CloudTrail, and centralized logging.
- Use account/environment boundaries and remote state separation for blast-radius control.

## Application platform

- ECS, EKS, Lambda, ALB, autoscaling, ECR, IAM roles for tasks, and secrets integration.
- Use reusable modules with versioned contracts and environment-specific composition.

## Data and storage

- S3 lifecycle policies, encryption, RDS, DynamoDB, backup, retention, and private access patterns.

## Reliability and operations

- CloudWatch metrics and alarms, multi-AZ design, disaster recovery, cost controls, drift detection, and policy-as-code.
