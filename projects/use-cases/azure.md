# Azure Terraform use cases

## Landing zone and governance

- Resource groups, subscriptions, management groups, naming, tags, Azure Policy, RBAC, and diagnostic settings.
- Use Terraform modules for repeatable environments and remote state for team collaboration.

## Application platform

- Azure App Service, Container Apps, AKS, managed identities, Key Vault, private endpoints, deployment slots, and autoscaling.
- Separate platform and workload state; review plans before production apply.

## Data and integration

- Azure Storage, Azure SQL, Azure Data Factory, private networking, retention, encryption, and monitoring.
- Model data domains and ownership as typed variables and module inputs.

## Reliability and operations

- Azure Monitor, Application Insights, alerts, SLO metadata, backup, disaster recovery, drift detection, and approved remediation.
