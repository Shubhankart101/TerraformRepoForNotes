# On-premises Terraform use cases

## Virtualization and private cloud

- VMware or Hyper-V VM provisioning, networks, storage, templates, naming, and ownership metadata.
- Use provider-specific modules and separate state per environment or platform boundary.

## Hybrid connectivity

- VPN, ExpressRoute or Direct Connect integration, DNS, routing, firewall rules, and identity federation.

## Configuration and operations

- Combine Terraform provisioning with Ansible configuration, patching, monitoring, backups, and CMDB metadata.

## Reliability and governance

- Model capacity, maintenance windows, disaster recovery, change approvals, drift detection, and safe rollback.
